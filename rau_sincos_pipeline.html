RAU sincos: Geometry and Algebra in One Pass

Warp the angle → build a vector → normalize with 1/√D → apply signs

1. Warp polynomial (angle → w)

Map the reduced fraction frac ∈ [0,1) to w ∈ [0,1] using a smooth polynomial (Estrin form).

\(v = \text{frac} - 0.5\)
\(y = v^2\)
\(p(v) = v\big[(C_0+C_1y+C_2y^2+C_3y^3) + y^4(C_4+C_5y+C_6y^2)\big]\)
\(w = 0.5 + p(v)\)
Coefficients (tier 0):
C0=0.78539828866558314  C1=0.64594625770051587
C2=0.63827326697947083  C3=0.62357916420830480
C4=0.75561600946878778  C5=0.079951715963356818
C6=1.8429558690126906

2. Quadrant reflection

For odd quadrants (Q1, Q3), use 1−w. This mirrors the vector across the diagonal.

3. Build normalized vector

From the (possibly reflected) w, form (w, 1−w) and rotate into the correct quadrant using in.

\(R_{vec} = \big(i_n.x\!\cdot\!(1{-}w) - i_n.y\!\cdot\!w,\; i_n.y\!\cdot\!(1{-}w) + i_n.x\!\cdot\!w\big)\)
(before normalization)

\(D = w^2+(1-w)^2 \quad (0.5 \le D \le 1)\)
in (axis basis):
z = mod(Q,4) = index of Q0 to Q3
(1,0) z<1   (0,1) z<2   (−1,0) z<3   (0,−1) z<4

4. Normalize with 1/√D

Divide by √D using a reciprocal-square-root polynomial (centered at 0.75) with one Newton refinement.

\(S_a = R_{vec} \cdot \dfrac{1}{\sqrt D} \;\rightarrow\; |S_a| = 1\)
\(P_{base}(d)\) centered at 0.75, \(d = D-0.75 \in [-0.25,0.25]\)
\(P(x) = \dfrac{1}{2}\dfrac{P_{base}(x)^2 + \tfrac{1}{x}}{P_{base}(x)}\)
\(P \approx \dfrac{1}{\sqrt x}\; \{0.5\le x\le 1\}\)

5. Final components

Both numerators share the same 1/√D.

\(\text{sin\_raw} = w\cdot\dfrac{1}{\sqrt D}\)
\(\text{cos\_raw} = (1-w)\cdot\dfrac{1}{\sqrt D}\)

Apply periodic signs (from qi) and the overall input sign (sin is odd, cos is even).

sign_sin = (qi>>1)&1  (periodic)
sign_cos = ((qi>>1)^qi)&1  (periodic)

7. Interpolation: uniform vs. non-uniform sweep

Skipping panel 1 entirely and feeding w = frac straight into panels 3–6 still lands exactly on the unit circle at every step — normalization (panel 4) guarantees that. What's lost is timing: the swept angle is no longer proportional to the input parameter. The two charts below compare the warped path (constant angular velocity, by construction) against the raw/unwarped path (a free, built-in ease-in–out).

warped θ=90°·t (uniform) unwarped θ=atan2(t,1−t)
Position: swept angle vs. raw parameter t
dθ/dt = 1 / D(t)
Sweep rate: slow at axis-aligned endpoints, fast through the diagonal middle
\(\dfrac{d\theta}{dt} = \dfrac{1}{D(t)}, \qquad D(t) = 2t^2-2t+1 \qquad\Rightarrow\qquad \dfrac{d\theta}{dt}:\; 1 \to 2 \to 1 \;\text{ as } t: 0\to0.5\to1\)
dθ/dt — slow·fast·slow Angle swept per unit of raw parameter. Slowest right at the cardinal endpoints (rate = 1), fastest at the diagonal midpoint (rate = 2, exactly double). This is the free ease-in–out: the point eases out of 0°/90° and eases back in, without any explicit smoothstep or cosine call.
dt/dθ = D(t) — fast·slow·fast The reciprocal view: how much raw parameter you need per unit of true angle. Largest at the endpoints (D=1, parameter has to move fast to keep up with true angle there), smallest at the midpoint (D=0.5). Same curve, opposite framing — whichever direction you're driving the system from.

Endpoints (t=0,1) and the quadrant midpoint (t=0.5) always land exactly on the true angle regardless of warp — both curves cross there. The warp polynomial (panel 1) exists purely to flatten dθ/dt to a constant 1 everywhere in between; dropping it keeps that natural bulge instead, which is either a timing error or a free easing curve depending on what the caller actually needs from t.
